Changing the number of bins changes the number of bars in the histogram (including the bars without any data). I chose 25 bins because it more clearly displays the breakdown of ratings between 3-4, where a majority of the observations fall. The 10 bin option was also appealing if we don’t need to have as close of a look at the ratings. I think the option really depends on what you’re trying to demonstrate with the graph.

chocolate_filtered <- chocolate %>%
  group_by(country_of_bean_origin) %>%
  filter(n() >= 50) %>%
  ungroup()

chocolate_filtered <- chocolate_filtered %>%
  mutate(
    cocoa_percent_num = as.numeric(substr(cocoa_percent, 1, 2)),
    cocoa_group = case_when(
      cocoa_percent_num < 60 ~ "<60%",
      cocoa_percent_num >= 60 & cocoa_percent_num < 70 ~ "60-<70%",
      cocoa_percent_num >= 70 & cocoa_percent_num < 90 ~ "70-<90%",
      cocoa_percent_num >= 90 ~ ">=90%"
    )
  )

chocolate_filtered <- chocolate_filtered %>%
  mutate(
    cocoa_group = fct_relevel(
      cocoa_group,
      "<60%",
      "60-<70%",
      "70-<90%",
      ">=90%"
    )
  )

ggplot(chocolate_filtered, aes(x = cocoa_group, y = rating)) +
  geom_boxplot() +
  facet_wrap(~ country_of_bean_origin) +
  labs(
    title = "Chocolate Ratings by Cocoa Percentage and Country",
    x = "Chocolate Percentage",
    y = "Rating"
  )

Based on a visual review of the plots, the chocolates with cocoa percentages between 60 & 70 and 70 & 90 seem to have better ratings, but there are differences between country of origin
