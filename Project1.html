    cocoa_percent_num = as.numeric(substr(cocoa_percent, 1, 2)),
    cocoa_group = case_when(
      cocoa_percent_num < 60 ~ "<60%",
      cocoa_percent_num >= 60 & cocoa_percent_num < 70 ~ "60-<70%",
      cocoa_percent_num >= 70 & cocoa_percent_num < 90 ~ "70-<90%",
      cocoa_percent_num >= 90 ~ ">=90%"
    )
  )

chocolate_filtered <- chocolate_filtered %>%
  mutate(

I graphed annual breakdowns of cocoa percentage related to chocolate rating as dot plots, including each dot representing the continent of the company location. Overall, a wild amount of variables to try to include in one graphic.

  1. I made the title useless as it doesn’t give the person viewing the graph any information on what they’re looking at.
  2. The x-axis label is only ‘percentage’, so the viewer wouldn’t know what the percentage is of. Since the graph is so busy, the x axis percentages are also illegible.
  3. I removed the y axis label.
  4. I removed the legned label, but left the variable name there (it doesn’t add value as anyone could tell they’re continents)
  5. I made all of the dots blue and most of them very close, so the color scale is useless.
  6. I made some of the text very small.
  7. I added a red line at the overall mean chocolate rating, but gave no context to what it is.

  1. I removed the varying color scale, the different colors didn’t add any additional information and were distracting

  3. I added a title, which helps a viewer more easily understand what this graph is showing.

  7. I also removed the legend as they’re all one color now.
